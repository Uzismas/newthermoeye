# ข้อเสนอความร่วมมือกับคลินิก/โรงพยาบาล — Eyezheimer (Thermoeye)

สถานะเอกสาร: ร่างสำหรับทีมใช้พูดคุย ไม่ใช่เอกสารขอจริยธรรม เนื้อหาทุกข้อตรงกับสถานะโค้ดจริง ณ วันที่เขียน

## 1. ตอนนี้ระบบทำอะไรได้ (พูดได้เต็มปาก)

- รับภาพ OCTA → ตรวจคุณภาพ → แบ่งเส้นเลือดด้วย U-Net (ONNX) → คำนวณ vessel density → ให้ผู้รีวิวบันทึกการตัดสินใจ → ออกรายงานวิจัย (PDF)
- ทำงานบนเครื่องในองค์กร ไม่ส่งภาพออกบริการ AI ภายนอกโดยค่าเริ่มต้น
- ผลวัดจริงชิ้นเดียวที่มี: Dice ของการแบ่งเส้นเลือดบนชุดข้อมูลสาธารณะ ROSE-O (ดู `backend/models/octa/model_card.json` และ `docs/ysc/`)

## 2. ตอนนี้ยังทำไม่ได้ (ห้ามพูดว่าทำได้)

- ไม่มีตัวจำแนก Alzheimer/MCI หรือโรคใด ๆ ค่า risk/confidence เป็น null เสมอ
- ไม่มีการตรวจสอบทางคลินิก ไม่เคยใช้ข้อมูลผู้ป่วยจริง
- ห้ามอ้างตัวเลข accuracy/sensitivity/AUC ของโรค เพราะไม่มีการทดลองที่ให้ตัวเลขนั้น

## 3. สิ่งที่ขอจากโรงพยาบาล (ทำให้ "โมเดลโรค" เป็นไปได้)

| รายการ | รายละเอียดขั้นต่ำ |
| --- | --- |
| การอนุมัติ | คณะกรรมการจริยธรรมการวิจัยในคน + หนังสือยินยอม + ข้อตกลงการใช้ข้อมูล (PDPA) |
| กลุ่มตัวอย่าง | ภาพ OCTA ของกลุ่ม Alzheimer / MCI / กลุ่มควบคุม ที่วินิจฉัยโดยแพทย์ระบบประสาทหรือ biomarker ที่ยอมรับ |
| ข้อมูลประกอบ | รหัสผู้ป่วยแบบไม่ระบุตัวตน (หนึ่งรหัสต่อคน), อายุ, เพศ, เบาหวาน, ความดัน, ต้อหิน, สายตาสั้น, รุ่นเครื่อง OCTA, ขนาดสแกน |
| ขนาดข้อมูล | กำหนดร่วมกับนักสถิติ ก่อนเริ่มเก็บ (ไม่ตั้งตัวเลขสุ่มสี่สุ่มห้าในเอกสารนี้) |
| ผู้ร่วมงาน | แพทย์ผู้ให้คำปรึกษา 1 ท่าน และนักสถิติ/ชีวสถิติ |

## 4. สิ่งที่ทีมเราจะทำ

1. กำหนด endpoint และแผนวิเคราะห์ก่อนดูข้อมูล (pre-registered plan)
2. แบ่ง train/validation/test ตาม "ผู้ป่วย" ไม่ใช่ตามภาพ และกันชุด test ไว้แตะครั้งเดียว
3. รายงาน sensitivity, specificity, AUC พร้อมช่วงความเชื่อมั่น รวมถึงผลลบหรือผลไม่ชัดเจน
4. ทดสอบกับข้อมูลจากอุปกรณ์/สถาบันอื่น (external validation) ก่อนพิจารณาใช้งานจริง
5. ให้แพทย์เป็นผู้ตัดสินเสมอ (human-in-the-loop) ระบบเป็นเพียงเครื่องมือสนับสนุนงานวิจัย

## 5. ขั้นตอนที่เสนอ

| ระยะ | เป้าหมาย | ผลลัพธ์ที่ตรวจสอบได้ |
| --- | --- | --- |
| A. สาธิต | ทดสอบ workflow กับภาพสาธารณะ/สังเคราะห์ร่วมกับแพทย์ | บันทึกข้อเสนอแนะจากการใช้งานจริง |
| B. ขออนุมัติ | ยื่นจริยธรรม + ข้อตกลงข้อมูล | เอกสารอนุมัติ |
| C. เก็บข้อมูล | รวบรวม cohort แบบไม่ระบุตัวตน | ชุดข้อมูลพร้อม data dictionary |
| D. ศึกษาความเป็นไปได้ | ทดลองตัวจำแนกโรคแบบ exploratory | รายงานผลตามแผนที่ลงทะเบียนไว้ |
| E. ประเมินจริง | locked test + external test | ผลที่พร้อมตีพิมพ์/ตัดสินใจต่อ |

ระยะ A ทำได้ทันทีด้วยระบบปัจจุบัน ระยะ B–E ขึ้นกับการอนุมัติและข้อมูลจากโรงพยาบาล
