# แบบทดสอบการใช้งานกับผู้ใช้จริง (Usability test) — Eyezheimer

ใช้ตอบข้อวิจารณ์ "ยังไม่ได้ทดสอบ" ด้วยหลักฐานจริง ทำได้ทันทีโดยไม่ต้องใช้ข้อมูลผู้ป่วย

## เตรียม

- ผู้ทดสอบ 3–5 คน (แพทย์/นักเทคนิคการแพทย์/นักศึกษาแพทย์) แยกทีละคน คนละ ~20 นาที
- เครื่องเดโม: `.\scripts\local-demo.ps1 start --offline` แล้วเปิด `http://127.0.0.1:3000`
- ภาพทดสอบ: `test-upload-images/` (ภาพสังเคราะห์/สาธารณะเท่านั้น)
- ผู้คุมจดเวลา + สิ่งที่ผู้ทดสอบพูด ห้ามช่วยกดหรือชี้ทาง

## งานที่ให้ทำ (อ่านให้ฟังทีละข้อ)

| # | งาน | ผ่านเมื่อ | เวลา (วินาที) | ผ่าน/ไม่ผ่าน | หมายเหตุ |
| --- | --- | --- | --- | --- | --- |
| 1 | เข้าสู่ระบบ | เห็นหน้า Dashboard | | | |
| 2 | อัปโหลดภาพ OCTA 1 ภาพ | เห็นผล vessel density | | | |
| 3 | หาว่าภาพนี้ผ่านเกณฑ์คุณภาพหรือไม่ | ตอบถูก | | | |
| 4 | อัปโหลดภาพที่ไม่ใช่ OCTA (เช่น รูปถ่ายทั่วไป) | ระบบบล็อกและผู้ทดสอบเข้าใจเหตุผล | | | |
| 5 | เปิด Task Manager แล้วบอกว่ามีงานอะไรค้าง | ตอบตรงกับหน้าจอ | | | |
| 6 | บันทึกการรีวิวและอนุมัติเคส | สถานะเปลี่ยนเป็น Approved | | | |
| 7 | ดาวน์โหลดรายงาน PDF | ได้ไฟล์ PDF | | | |

ข้อ 8 สำคัญที่สุด: ถ้าผู้ทดสอบเข้าใจผิดว่าระบบวินิจฉัยโรคได้ ต้องแก้ข้อความใน UI

## คำถามหลังทดสอบ (คะแนน 1–5)

1. ใช้งานง่าย
2. เข้าใจว่าตัวเลขแต่ละตัวหมายถึงอะไร
3. หน้าจอดูน่าเชื่อถือ/เป็นทางการ
4. อยากใช้ต่อในงานวิจัย
5. สิ่งที่สับสนที่สุดคืออะไร (ตอบเป็นข้อความ)

## สรุปผล

- อัตราสำเร็จต่องาน = จำนวนคนที่ผ่าน / จำนวนคนทั้งหมด
- เวลาเฉลี่ยต่องาน
- ปัญหา 3 อันดับแรก + สิ่งที่แก้แล้ว (ใส่ภาพก่อน/หลัง)

ผลชุดนี้ใช้ในสไลด์ได้ว่า "ทดสอบกับผู้ใช้ N คน" — ห้ามเขียนว่าเป็นการทดสอบทางคลินิก
